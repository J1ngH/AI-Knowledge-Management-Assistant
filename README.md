## 🎯 项目概述

在信息过载环境下，高频学习用户每天接触大量碎片化内容（课程资料、PDF、网页链接、公众号文章、截图笔记等），但收藏后很少回看，知识难以真正沉淀。传统笔记工具解决的是"存储"问题，而非"掌握"问题。

**AI知识管理助手**利用大语言模型、向量检索和智能体能力，将知识管理从"被动记录工具"升级为"主动知识助手"。AI 承担内容解析、自动摘要、知识卡片生成、智能分类、语义检索和复习提醒等工作，帮助用户降低整理成本，提高长期记忆效率。

## 🎨 核心功能

### 1. 多源内容导入
- 📄 **文档导入**：支持 PDF、Word、PPT 等格式，AI 自动解析正文
- 🔗 **链接导入**：粘贴网页链接，AI 提取核心内容并总结
- 📸 **截图导入**：OCR 识别截图内容，提取关键信息
- 💬 **微信导入**：支持手动粘贴/截图导入微信文章

### 2. AI智能加工
- 📝 **自动摘要**：提炼核心内容与关键结论
- 🏷️ **智能标签**：自动生成标签并归类
- 🃏 **知识卡片**：将长文转化为适合复习的问答卡片
- 🔗 **关联推荐**：自动发现与已有知识的关联

### 3. 知识库管理
- 🔍 **语义搜索**：支持模糊表达和语义相关搜索
- 📂 **标签筛选**：按类型、标签、时间等多维度筛选
- 🧠 **AI补充建议**：识别知识盲区并给出学习建议
- 📊 **知识资产统计**：可视化知识沉淀进度

### 4. 智能复习系统
- 📅 **今日复习任务**：基于遗忘曲线自动生成
- ⏰ **遗忘风险提醒**：主动提醒即将遗忘的知识
- 📈 **掌握度追踪**：量化学习效果并动态调整计划
- ✍️ **AI自测题**：基于知识卡片生成测试题目

## 📊 产品指标设计

| 指标类型 | 指标名称 | 说明 |
|----------|----------|------|
| **北极星** | 每周有效复习知识点数 | 反映知识入库质量和复习机制有效性 |
| 激活指标 | 首次导入完成率 | 新用户是否完成第一次内容导入 |
| 质量指标 | AI加工结果确认率 | 用户是否认可 AI 生成结果 |
| 使用指标 | 每周入库知识数 | 用户是否持续沉淀内容 |
| 留存指标 | D7/D30 留存率 | 产品是否形成长期价值 |

## 💡 产品设计思路

1. **闭环优先**：不满足于"收藏"，强调从输入到复习的完整链路
2. **AI 做减法**：AI 负责加工整理，降低用户操作成本，而非增加功能复杂度
3. **渐进式信任**：AI 生成内容入库前必须经用户确认，避免自动污染知识库
4. **量化驱动**：所有 AI 能力均设计可量化评测指标，关注摘要准确率、标签采纳率等
5. **移动端优先**：高频学习场景以手机为主，电脑辅助
